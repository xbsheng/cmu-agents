## 阅读约定

- **页码**：正文中的 `Slide N` 指该讲 PDF 的第 N 页。
- **时间戳**：形如 `12:34` 的链接直接跳到 YouTube 对应位置；9a 无录像，因此没有时间戳。
- **图片**：关键 slides 以 WebP 格式、原始 PDF 的 2–3 倍分辨率渲染，点击图片可查看大图。
- **术语**：中文叙述 + 英文术语；首次出现时给出英文原文，便于查论文。
- **范围**：笔记是二次整理，不替代原始课件；公式和数字以课件为准。
